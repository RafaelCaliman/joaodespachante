# Site João Despachante — Projeto Extensionista UEMG

### 🚀 Sobre o Projeto
Este site foi desenvolvido como parte de um **projeto extensionista** da **UEMG (Universidade do Estado de Minas Gerais)**. O objetivo foi aplicar os conhecimentos acadêmicos para atender uma demanda real da empresa **João Despachante**, criando uma vitrine digital para apresentação de seus serviços e facilitação do contato com clientes.

Este foi o meu primeiro projeto entregue para um cliente real, unindo a prática de desenvolvimento web com a extensão universitária.

### 🛠️ Tecnologias Utilizadas
* **HTML5:** Estrutura semântica focada em SEO.
* **CSS3:** Estilização personalizada e layout responsivo para dispositivos móveis.
* **GitHub Pages:** Hospedagem e deploy automatizado.

### 📈 Aprendizados e Evolução
O desenvolvimento deste projeto foi um marco na minha trajetória como desenvolvedor, pois permitiu:
1.  **Interface com o Cliente:** Traduzir as necessidades de um negócio físico para o ambiente digital.
2.  **Responsividade:** Garantir que os clientes do João Despachante pudessem acessar o site perfeitamente pelo celular.
3.  **Resolução de Problemas:** Superar desafios técnicos de deploy e organização de arquivos (caminhos relativos e sensibilidade a maiúsculas/minúsculas).
